# Faith record contracts

`PrayerRecords.sol` defines prayer records. `HolderFaithRecords.sol` defines holder-gated confession and praise. These record contracts are separate from any externally issued token.

Prayer has no token fee. Holder-gated records check a whole-token holding requirement without deducting or burning tokens. Deployment bindings are supplied separately and are not included in this repository.

Public blockchain data is observable and cannot promise anonymity or deletion. A hidden display name does not hide the submitting wallet. Never submit private faith text without understanding the applicable privacy mode and irreversible nature of a blockchain record.

Contract deployment and real-money use require explicit authorization, independent review and verified configuration. This alpha source is not an independent security audit.
